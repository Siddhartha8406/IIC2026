# NCC Statutory Documents Repository (1 KAR BN NCC)

This folder is the **default local repository** for all mandatory NCC returns, cadet enrollment forms, camp nominal rolls, and finance acquittance rolls.

### Included Official Files:
1. `sd_enrollment_forms_2026.pdf` (Form I - Senior Division Enrollment)
2. `parent_consent_declarations.pdf` (Form II - Parent/Guardian Consent & Indemnity)
3. `medical_fitness_master_2026.pdf` (Form III - Medical Fitness Certifications)
4. `catc_ii_nominal_roll_45cdt.xlsx` (CATC-II Camp Nominal Roll)
5. `camp_indemnity_bonds_bundle.pdf` (Camp Risk Indemnity Bonds)
6. `ammo_expended_voucher_2026.pdf` (Range Safety Protocol & Ammunition Expended)
7. `b_cert_eligibility_roster.pdf` (B Certificate Examination Eligibility)
8. `c_cert_nomination_master.pdf` (C Certificate Examination Directorate Nomination)
9. `refreshment_acquittance_aug2026.pdf` (Refreshment Allowance Acquittance Roll)
10. `uniform_stores_issue_ledger.pdf` (Uniform & Military Stores Issue Vouchers)

*Note: You can link a custom external folder (e.g. on a USB drive) from the ANO Document Tracker at any time.*
